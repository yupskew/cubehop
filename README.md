# Cube Hop

A lightweight browser-based arcade jumper built with pure HTML5 Canvas and vanilla JavaScript, packaged as a single standalone URI string.

## how to use it





how it works
Game Loop: Powered by requestAnimationFrame, updating physics, scrolling obstacles, and redrawing the frame continuously.

Input System: Listens to keyboard and pointer clicks, mapping them seamlessly to desktop and mobile controls.

Physics: Uses a simple velocity and gravity model for smooth jumping mechanics.

Procedural Spikes: Dynamically spawns obstacles at randomized intervals while progressively ramping up game speed as distance increases.

Collision & Resets: Detects bounding box overlaps between the player and spikes, triggering a quick reset and incrementing attempt counters on death.
